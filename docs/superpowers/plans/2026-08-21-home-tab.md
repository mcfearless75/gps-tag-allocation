# Home Tab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the app a neutral landing route (`/`, a new "Home" tab) so opening the app or switching tabs back to it no longer forces the operator into ScanPage's live camera view.

**Architecture:** One new static page (`HomePage.tsx`, three link cards to Scan/Roster/Report, no data fetching), wired in as the default route in `App.tsx` and as the leading item in `AppShell`'s bottom nav. `ScanPage` itself is untouched.

**Tech Stack:** React 18, react-router-dom v6, Vitest + Testing Library (existing stack, no new dependencies).

## Global Constraints

- No new npm dependencies.
- Match existing code style: named function exports for pages/components, CSS classes (not inline styles) defined in `src/App.css`, existing card/spacing design tokens (`--space-*`, `--radius*`, `.card`).
- Keep files under 500 lines (not a concern for this plan's small files, but stated per project convention).

Create `src/pages/HomePage.tsx`:

```tsx
import { Link } from 'react-router-dom';

interface HomeLink {
  to: string;
  title: string;
  description: string;
}

const HOME_LINKS: HomeLink[] = [
  { to: '/scan', title: 'Scan', description: 'Check tags out and back in for a session.' },
  { to: '/roster', title: 'Roster', description: 'View and manage the active squad.' },
  { to: '/report', title: 'Report', description: 'Weekly allocation report and exports.' },
];

export function HomePage() {
  return (
    <main>
      <h1>Welcome</h1>
      <div className="card home-links">
        {HOME_LINKS.map((link) => (
          <Link key={link.to} to={link.to} className="home-link-card">
            <span className="home-link-title">{link.title}</span>
            <span className="home-link-desc">{link.description}</span>
          </Link>
        ))}
      </div>
    </main>
  );
}
```
